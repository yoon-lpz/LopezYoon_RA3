# Game Description

**Genre**: 2D Platformer

Experience a shape-shifting 2D side-scroller that takes you across different eras. Begin your quest as a caveman in the dark depths, transform into a wizard in a futuristic city, and become a sharpshooting archer in a village, before returning to your caveman roots for the final challenge.

# Controls

* **Movement**: `A` and `D`
* **Change gravity**: `0` (not the numeric pad)
* **Quit the game**: `M`
